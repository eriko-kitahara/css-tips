CSS TIPS · No.32 · アニメーションcalc-size() / interpolate-size

height: auto へのアニメーションが可能になりつつある

最新CSSで、height: auto への開閉アニメーションが可能になりつつある

TRY IT「▶ 開閉する」ボタンで、左右の開き方を比べてください（マウス・タップ・キーボードで操作できます）

最新CSS・対応注意interpolate-size は対応ブラウザが限られる新しいCSSです。未対応の環境では、従来どおりパッと開閉します（表示が壊れるわけではありません）。案件で使う前に、対応ブラウザとフォールバックを必ず確認してください。

お使いの端末は「動きを減らす」設定です。ページ装飾の動きは止めていますが、このデモは動きを見ること自体が学習内容のため、ボタンなどで操作したときは動きます。

→
BEFORE

height: 0 → auto がそのままでは動かない

height: 0 から height: auto へは、そのままでは補間できず、パッと開く

よくある質問

高さが auto の要素は、これまで高さのアニメーションの対象にできませんでした。

AFTER

対応ブラウザではCSSだけで開閉できる

interpolate-size: allow-keywords を足すと、auto への高さ変化も補間される（対応ブラウザのみ）

よくある質問

高さが auto の要素は、これまで高さのアニメーションの対象にできませんでした。

混同しやすい2つの違い

interpolate-sizecalc-size()
種類プロパティ（設定）CSS関数
役割auto などのキーワードへの変化を、補間してよいと許可するauto などのサイズを、計算式の中で扱えるようにする
書き方の例interpolate-size: allow-keywords;height: calc-size(auto, size);

用途

アコーディオンなど、内容量が変わる要素の高さをJSで計測せずにアニメーションしたいとき

注意

最新CSS枠。案件投入前に対応ブラウザとフォールバック確認。 未対応ブラウザでは補間されず、パッと開閉する。その状態でも使えるかをフォールバックとして確認する。interpolate-size（設定）と calc-size()（関数）は別の機能で、どちらも新しい。
