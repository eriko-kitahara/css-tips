CSS TIPS · No.35 · カラー・ダークモードlight-dark()

ライト／ダークの色指定を1つにまとめる

color-scheme と組み合わせて、ライト／ダークの色を1つの宣言で切り替えられる

前提light-dark() は color-scheme の指定とセットで使います。color-scheme を指定しないと、常に1つ目（ライト）の値になります。

→
BEFORE

配色の分岐を別々に書く

メディアクエリで、ライトとダークの値を別々の場所に書く

body { background: #fff; color: #111; } @media (prefers-color-scheme: dark) { body { background: #111; color: #f5f5f5; } }
AFTER

light-dark()で1つの宣言にまとめる

1つの宣言に、ライト時の値とダーク時の値を並べて書く

:root { color-scheme: light dark; } body { background: light-dark(#fff, #111); color: light-dark(#111, #f5f5f5); }

color-scheme しだいで、同じ light-dark() の結果が変わる

下の4枚はすべて同じ light-dark() の指定です。違うのは color-scheme だけです。

color-scheme: light

1つ目（ライト）の値

ボタン

color-scheme: dark

2つ目（ダーク）の値

ボタン

color-scheme: light dark

OS・ブラウザの設定に従う（いまの設定が反映）

ボタン

指定なし

常に1つ目（ライト）の値。OSがダークでも変わらない

ボタン

用途

ライト／ダーク両対応のサイトで、配色の分岐をシンプルに書きたいとき

注意

color-scheme指定とセットで確認。案件ではフォールバック検討。
